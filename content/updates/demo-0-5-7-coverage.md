Guildrun Hub’s public database and strategy pages now track **Demo 0.5.7**. That means hero kits, relic text, item effects, class playbooks, and curated builds are normalized against the current Demo sheet dump — not an older 0.5.1 archive.

## What this means for players

- Look up shop offers against **0.5.7** wording and tags (Rush, Stall, Crit, class banners).
- Prefer [Builds](/builds) and the [Tier List](/tier-list) when you need a full team plan for this Demo.
- Recheck balance-sensitive numbers after future patches — sheet dumps can lag Steam notes by a few days.

## Where to start on the hub

1. [Getting Started](/guides/getting-started) — run loop, drafting, and loss diagnosis.
2. [Tier List](/tier-list) — ranked team builds first, hero grades second.
3. [Heroes](/heroes) / [Relics](/relics) / [Items](/items) — fast lookup when a shop row is unfamiliar.

If you find a wrong effect or a missing link after a patch, use [Contact](/contact) with the page URL.
