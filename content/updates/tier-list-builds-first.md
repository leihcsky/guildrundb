Searching *Guildrun tier list* usually means “what should I play right now?” In an autobattler, that answer is a **team package** — heroes, items, relics, and shop rules — not a single letter next to a portrait.

## What changed on the page

The [Guildrun Tier List](/tier-list) now leads with ranked **builds**:

- **S** — Rush Duelists, Aria Stall Mage, Irini Starter
- **A** — Mystic Sustain, Warrior Shield Core
- **B** — Assassin Backline

Each card shows a loadout snapshot (core heroes, key items, key relics) plus why the grade exists. Hero S–D rankings stay on the same page as a shop aid when you only need to judge one offer.

## How to use it mid-run

1. Match the shop seed to a build card (Rush banners → Rush Duelists; Mage/Stall → Aria).
2. Open the full [build page](/builds) for positioning and Shard order.
3. Use hero grades only when drafting a flex pick or checking a new face in the shop.

We update the list when Demo balance or our testing notes change. The version label and changelog on the tier list page always show which patch the rankings reflect.
